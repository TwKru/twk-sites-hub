# TwK Sites Hub

Публичная подборка шести проектов Тимофея. Превью сняты с действующих сайтов, оригиналы не изменены.

Фильтры, поиск и копирование работают в браузере. Данные посетителей не собираются. При недоступном Clipboard API открывается окно для ручного копирования.

Для нового проекта обновите index.html, projects.json, количество в фильтрах и добавьте превью в assets. projects.json служит справочником, карточки доступны без JavaScript.

Не включены снятая с публикации версия Mayak v2 и заменённый FORMA старый адрес NOVUS.

Шрифт Golos Text: OFL, лицензия assets/Golos-OFL.txt.

## Обновление визуала
Тёмное портфолио с лаймовыми и сиреневыми акцентами. На первом экране переключаются FORMA, BLACK BRUSH и Маяк. Реальные превью проектов, выделенные карточки FORMA и TwK, адаптивная сетка, поиск, фильтры и копирование ссылок. Новые внешние зависимости и аналитика не добавлены.
